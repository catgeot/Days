### Q9 — `/korea` 즐겨찾기 다건 → TripWindow

**쉬운 설명**: `/korea`에서 하트로 여러 축제를 즐겨찾기하면, 날짜가 제각각입니다.  
예: A축제 5/1–5/5, B축제 5/10–5/15, C축제 6/1–6/3.

**질문**: 즐겨찾기 목록에 **「이 축제들 기간으로 여행 잡기」** 버튼을 넣을 때, 체크인·체크아웃을 **합집합**(5/1~6/3)으로 자동 계산할까요?

| 선택 | 설명 |
|------|------|
| **A** | P1 필수 — 즐겨찾기 탭에 합집합 TripWindow CTA |
| **B** | P1.5 — 단일 축제 상세 CTA만 먼저, 다건은 나중 |
| **C** | 안 함 — 즐겨찾기는 목록만 |
