## 1. 제안 계층 (신설)

```
권역(대) → 시도(중) → 세권(신설) → 시·군 hub(소)
```

| 단계 | aria / 역할 | 목표 개수 | 목표 건수 |
|------|-------------|----------:|----------:|
| 권역 | 대분류 | 6 | — |
| 시도 | 중분류 | 권역당 1~5 | — |
| **세권** | **지역 묶음** | **시도당 3~5** (경기는 **4**) | **세권당 15~45** |
| hub | 소분류 | **세권당 3~9** | hub당 기존 유지 |

### 노출 규칙

1. **세권 SSOT가 있는 시도만** 세권 행 표시 (아래 8개).
2. 세권 없는 시도(서울·인천·제주·광역시 등) → 지금처럼 hub만.
3. 강원·제주처럼 시도 칩이 1개인 권역 → 권역 선택 후 **세권 → hub** (시도 행 생략 유지).
4. 기본값(#110 연장): 권역 → (시도) → **첫 세권** → 그 세권의 hub. 목록은 세권 단위로 시작.
5. 세권 「전체」칩은 두지 않음(권역 「전체」와 동일 정책). 같은 세권 재클릭으로 상위 해제는 하지 않음.

### URL (구현 시)

명소 파드: `cregion` / `carea` / **`ccluster`** / `hub`  
(명승·관광지 파드와 분리 유지)

## 4. 대안 (기각·보류)

| 안 | 내용 | 판단 |
|----|------|------|
| A. hub만 줄이기 (시·군 합치기) | 예: 성남∪수원, 가평∪남양주 | **보류** — 여행지 단위 의미가 흐려짐. 세권이 더 안전 |
| B. 권역을 잘게 (경기북/경기남을 대분류로) | 대분류 칩 증가 | **기각** — 권역 6개 한눈 유지 |
| C. 종목(산·사찰…)으로 지역 대체 | Tour cat | **기각(명소 파드)** — 지역 탐색이 1차 니즈. 관광지 파드에 이미 있음 |
| D. 세권 없이 기본 hub만 | #110 | **불충분** — 경기 칩 31개는 남음 |
| E. 경기 7세권(서북·동북…) | 생활권 세분 | **기각** — 통칭 약함 → **동서남북 4세권** 채택 |
| F. 경기 행정 2분(북/남)만 | 도청 관행 | **기각(단독)** — 남부 hub 21개 잔존 |

**채택**: 세권 신설 · **경기는 동·서·남·북 4세권** (본 문서 §2.1).
