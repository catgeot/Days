## 0. 한줄 요약

제안(빈 지구본 → 공식 대륙/중분류/국가 계층 선택 → 윤곽 피스를 맞춰 넣기 · 점수 1/2/3 · 쉬운→어려운 대륙 · 대양 중간 시험)은 **학습 효과와 gateo 지구본 자산에 잘 맞는다**.  
같은 **장르**는 이미 많지만, **규칙·점수·장르 자체는 저작권 보호 대상이 아님**. 위험은 UI/아트/카피/상표 복제.  
gateo 차별점은 **3D Mapbox 지구본 + 계층 진행 + 대양 시험 + 여행 서비스 연결**이다.

## 1. 제안 평가

### 1.1 잘 맞는 점

| 포인트 | 이유 |
|--------|------|
| **빈 지구본 → 피스 장착** | 능동 회상(active recall) — 「리스트만 읽기」보다 위치·윤곽 학습에 유리 |
| **대륙 1 · 중분류 2 · 국가 3점** | 난이도·노력에 비례한 보상. 초보→숙련 곡선이 자연스러움 |
| **쉬운 대륙 → 어려운 대륙** | 남아메리카/오세아니아(국가 수·형태 뚜렷) → 유럽·아프리카(밀집·소국) 순이 일반적 학습 경로 |
| **공식 대륙·대양 명칭** | 홈 「휴양/자연/도시…」5면은 **권역≠테마**(여행 UX). 게임은 **공식 지리 명칭**으로 분리하면 학습·브랜드 모두 명확 |
| **대양·세부 해역 시험** | 산호해·에게해 등은 「국가만」게임과 차별화. 중간 보스(체크포인트)로 리듬감 |
| **기존 자산 재사용** | 나라 카탈로그 219 · bbox · 중분류 · Mapbox fitBounds/하이라이트 이미 동작 |

### 1.2 보완이 필요한 점

| 리스크 | 대응 |
|--------|------|
| **드래그-스냅이 3D 지구본에서 어려움** | MVP는 「선택 리스트 → 지구본 클릭/드롭존」또는 「피스 탭 → 자동 flyTo 후 확인」. 정밀 드래그는 Phase 2+ |
| **마이크로국가·섬** | 바티칸·나우루 등은 윤곽 식별이 거의 불가 → 핀/확대 힌트·별도 「섬 모드」 |
| **분쟁·인식 국가** | 카탈로그의 TW/PS/XK 등 이미 포함. 게임 카피·크레딧에 「교육용 경계 · Mapbox/데이터 출처」명시 |
| **홈 UX와 혼선** | 게임은 **별 모드/라우트**(`/play` 또는 Zen 옆 진입). 홈 여행 칩·카테고리 면과 **명칭·UI 분리** |
| **대양 폴리곤 SSOT 부재** | 국가 bbox는 있음. 해역은 신규 데이터(또는 근사 bbox + 라벨) 필요 — Phase 1.5 |
| **전체 세계 한 번에** | 219국 풀런은 피로도 큼 → 대륙 캠페인 + 일일 N피스 + 「시험」스테이지로 쪼개기 |

### 1.3 결론

**방향 추천: 진행해도 좋다.**  
다만 MVP는 「전 세계 드래그 퍼즐」이 아니라 **계층 퀴즈 + 윤곽 하이라이트 + 지구본에 채우기**로 시작하고, 드래그-스냅은 검증 후 확장하는 것이 안전하다.

## 2. 유사 게임·표절 리스크

### 2.1 같은 장르 (이미 존재하는 것)

| 제품 | 핵심 루프 | gateo와의 겹침 |
|------|-----------|----------------|
| **Seterra** (GeoGuessr) | 지도 클릭·윤곽·대륙·대양 퀴즈 수백 종 | 퀴즈/윤곽 — 높음. UI·문제 은행은 다름 |
| **ReMap World** (GeoFunGames) | 국가 피스를 **빈 지도 윤곽**에 드래그 | 피스 배치 — 높음 (2D) |
| **Enjoy Learning World Map Puzzle** | 하단 피스 → 지도 스냅 · 국경/이름 없는 고난도 | 퍼즐 장착 — 높음 (2D) |
| **Planeta 42 World Map Puzzle** | 7대륙 조각을 실루엣에 맞춤 | 대륙 조립 — 중간 |
| **GeoPuzzle** | 지역 선택 후 피스 배치 · OSM 경계 | 퍼즐 — 중간 |
| **Stack the Countries** | 퀴즈 정답 → 국가 **도형 물리 스택**(맵 배치 아님) | 국가 도형 — 낮음(메커닉 다름) |
| **Worldle / Mappr shapes** | 단독 실루엣으로 국가 맞히기 | 윤곽 인식 — 부분 |
| **Globle / GuessGlobe / Mappil / Geo Quizzer** | 3D 지구본에서 국가 추측·클릭 | 3D 글로브 — 중간 (퍼즐 피스 없음) |
| **Sheppard Software** 등 교육 사이트 | 클릭·드래그 지도 학습 | 교육 루프 — 중간 |

**요약**: 「빈 지도에 국가/대륙을 맞춘다」「윤곽으로 학습한다」는 **1990년대부터 흔한 교육 장르**다. gateo만의 발명은 아니다.

### 2.2 법적·평판 리스크 (실무)

| 구분 | 보호 여부 | 실무 가이드 |
|------|-----------|-------------|
| **게임 규칙·장르·점수(1/2/3)·계층 진행** | 저작권 **비대상**(아이디어·시스템) | 동일 장르여도 **합법적으로 가능** |
| **타사 UI, 아트, 아이콘, 사운드, 카피, 레벨 문구** | **보호됨** | 복제 금지 · 자체 디자인 |
| **상표명** (Seterra, Stack the Countries, Worldle 등) | 상표 | 이름·로고·「공식 클론」표현 금지 |
| **지도 데이터** | 라이선스(Mapbox ToS, Natural Earth, OSM 등) | 기존 Mapbox attribution 유지 · 외부 GeoJSON은 라이선스 확인 |
| **「표절」여론** | 법≠평판 | **카피캣 UI**면 법 이전에 평판 타격. 차별화·자체 카피로 회피 |

미국 Copyright Office: *게임의 아이디어·플레이 방법은 저작권 보호 대상이 아님. 규칙 텍스트·그래픽 표현은 보호될 수 있음.*

**권고**: 「Seterra/ReMap 클론」이 아니라 **gateo 지구본 학습 모드**로 포지셔닝. 마케팅에 타사 명칭·스크린샷 대비 표 남용 금지.

### 2.3 gateo만의 차별화 (표절 논란 완충)

1. **이미 있는 3D Mapbox 여행 지구본** 위에 「채우기」진행 (대부분 경쟁작은 2D SVG)
2. **공식 대륙 → 중분류 → 국가** 점수 계층 + **대양 중간 시험**
3. **한국어 우선** 공식 지명 + (선택) 영문 병기 학습
4. 맞춘 국가 → **여행 카드·항공/숙소로 이어지는 CTA**(후속) — 순수 교육 앱과 목적 다름
5. 홈 5면(휴양·자연…)과 **게임용 공식 지리 트리 분리** — UX·학습 명칭 충돌 방지

## 3. 제품 정의 (권장)

### 3.1 워킹 타이틀 (가칭)

- 내부: `GlobeFill` / `GeoPiece`
- 사용자-facing은 확정 전 보류 (예: 「지구 맞추기」「피스 지구본」). **타사 상표와 겹치지 않게** 별도 네이밍 세션.

### 3.2 코어 루프 (방법1 정제)

```
[빈 지구본] 지명·국경 숨김
    → 선택 패널: 공식 대륙 | 대양
    → (대륙 선택) 중분류 리스트
    → (중분류 선택) 국가 리스트
    → 해당 피스 윤곽+지명 미리보기
    → 지구본 목표 위치에 맞춤(클릭 확정 / 스냅)
    → 점수 · 채움 애니메이션 · 다음 피스
    → 대륙 클리어 시 대양/해역 「시험」스테이지 (선택)
```

### 3.3 점수 (제안 확정안)

| 맞춤 단위 | 점수 | 비고 |
|-----------|------|------|
| 대륙 | **1** | 실루엣이 크고 쉬움 |
| 중분류(동아시아 등) | **2** | 공식 UN/통용 소지역명 |
| 국가 | **3** | 기본 단위 |
| 대양(5대양) | **2** | 대륙과 교대 배치 |
| 세부 해역(산호해·에게해 등) | **3~4** | 「시험」스테이지 · 보너스 |

콤보: 연속 정답 N회 → ×1.1 (옵션). 오답: 목숨 없음(학습형) 또는 힌트 소모(챌린지형) — MVP는 **학습형(무제한·힌트)**.

### 3.4 난이도 캠페인 순서 (초안)

쉬운 → 어려운 대륙(국가 수·윤곽 유사성 기준):

1. **오세아니아** (섬·형태 뚜렷 · 소수부터)
2. **남아메리카**
3. **북아메리카**(본토+중미 분리 가능)
4. **아시아**(중분류 단위로 쪼개 진행)
5. **아프리카**
6. **유럽**(밀집·소국)
7. **남극**(특수 · 선택)

대양 트랙(병행): 태평양 → 대서양 → 인도양 → 남극해 → 북극해 → **세부 해역 시험**.

## 4. 데이터·SSOT 설계

### 4.1 재사용

| 기존 | 게임 역할 |
|------|-----------|
| `GLOBE_COUNTRY_CATALOG` | 국가 id · labelKo · iso · bbox · lat/lng |
| `globeFaceSubregions` | **참고만** — 홈 권역(paradise…)용. 게임용 **공식 지리 트리**는 별도 SSOT 권장 |
| Mapbox 국경/하이라이트 · fitBounds | 피스 미리보기·정답 채움 |
| `smoke:place-label-slug` | 라벨·slug 회귀 |

### 4.2 신규 SSOT (권장)

`src/pages/Home/data/geoPuzzleTree.json` (또는 `src/data/geoPuzzle/`)

```text
continents[]     id, labelKo, labelEn, countryIds[], difficultyRank, bbox
subregions[]     id, continentId, labelKo, labelEn, countryIds[], difficultyRank
oceans[]         id, labelKo, labelEn, bbox?, difficultyRank
seas[]           id, oceanId?, labelKo, labelEn, bbox, examOnly: true
campaign[]       stageType, refId, unlockAfter[]
```

- **홈 5면 트리와 분리** (권역≠공식 대륙).
- 중분류 명칭: 「동아시아」「동남아시아」「서유럽」 등 **통용 공식/교과서 명칭**.
- 생성 스크립트: catalog iso 기준으로 tree 커버리지 audit (`npm run audit:geo-puzzle` 예정).

### 4.3 대양·해역

- Phase 1: 5대양 + 소수의 유명 해역(지중해·카리브·산호해·남중국해·에게해·북해 등 **10~20개**) bbox 근사.
- Phase 2: Natural Earth / 해양 폴리곤(라이선스 확인)으로 면 하이라이트.
- Mapbox water 레이어만으로는 「에게해」클릭 판정이 약함 → **명시 bbox/폴리곤** 필요.

### 4.4 경계·정치

- 교육용 고지 + Mapbox/데이터 attribution.
- 분쟁 지역은 카탈로그 정책을 따르고, 게임 카피에 정치적 주장 문구 넣지 않음.

## 5. UX·기술 설계

### 5.1 진입

- 홈: Zen/테마와 겹치지 않는 **별도 진입**(예: 로고 패널·숨은 메뉴·`/play/geo`).
- **UI 임의 변경 금지** 규약: 홈 기존 버튼·레이아웃을 뜯지 말고 **추가 진입점**만 (사람 승인 후 카피·위치).

### 5.2 모드

| 모드 | 설명 | 우선 |
|------|------|------|
| **캠페인** | 쉬운 대륙→어려운 · 스테이지 클리어 | MVP |
| **연습** | 대륙/중분류 골라 자유 연습 | MVP |
| **시험** | 대양·해역 · 타이머·힌트 제한 | Phase 1.5 |
| **일일** | 그날 N피스 (공유 그리드 선택) | Phase 2 |
| **챌린지** | 목숨 3 · 드래그 스냅 | Phase 2+ |

### 5.3 입력 (MVP → 고도화)

1. **MVP (권장)**: 리스트에서 피스 선택 → 지구본이 후보 영역으로 flyTo → **「여기에 놓기」확인** 또는 지도 클릭이 bbox/폴리곤 히트면 성공. 오답 시 약한 흔들림+힌트.
2. **Phase 2**: 사이드 패널 실루엣 드래그 → 지구본 위 드롭 · 각거리/폴리곤 contain으로 스냅.
3. **모바일**: 드래그보다 **탭-확정**이 안정적.

### 5.4 시각

- 초기: 위성/지구 텍스처만 · **지명·행정 경계 레이어 off**.
- 정답 시: 해당 피스가 「채워짐」(하이라이트 fill) · 라벨 on · 점수 팝.
- 홈 여행 마커·카테고리 칩은 게임 모드에서 **숨김**.

### 5.5 기술 스케치 (구현 시)

- 라우트: `/play/geo` (또는 쿼리 `?mode=geo-puzzle` — 홈 오염 최소화로 **별 라우트 선호**).
- 상태: `filledIds` · `score` · `stage` · `hintsLeft` — `localStorage`로 캠페인 진행 저장.
- Mapbox: 기존 `HomeGlobeMapbox` 패턴 재사용하되 **게임 전용 얇은 래퍼** (홈 핸들러와 분리 — 회귀 방지).
- 히트 테스트: catalog `bbox` → 정밀화 시 country GeoJSON (Natural Earth 110m/50m).

## 6. 페이즈 계획

### Phase 0 — 합의 (구현 전)

- [ ] 방법1 루프·점수·캠페인 순서 확정
- [ ] 진입점·이름(가칭) 사람 승인
- [ ] MVP 입력 = **탭/클릭 확정** (드래그 보류) 합의
- [ ] 대양 시험 포함 여부(MVP vs 1.5)

### Phase 1 — MVP (플레이 가능 최소)

범위:

- 공식 대륙 트리 SSOT (아시아 중분류까지) + 국가 연결
- 빈 지구본 + 리스트 선택 + fitBounds + 정답 채움
- 점수 1/2/3 · 로컬 진행 저장
- 오세아니아·남아메리카·아시아(동아시아) **3개 캠페인 스테이지**만
- audit 스크립트: tree 커버리지 · 중복 countryId 0

비범위: 드래그 스냅 · 전 세계 풀 · 대양 폴리곤 · 리더보드 · 여행 CTA

**검증**: 수동 QA 체크리스트 + `audit:geo-puzzle` + 기존 `smoke:place-label-slug`(회귀)

### Phase 1.5 — 대양·시험

- 5대양 + 해역 10~20 · exam 스테이지
- 힌트/타이머 옵션

### Phase 2 — 고도화

- 드래그-스냅 · 일일 챌린지 · 전체 대륙 캠페인
- 맞춘 국가 → 여행 카드/Explore soft CTA
